## MAX 解决了什么问题

一个典型的企业设计系统通常包含数百到数千个组件。现有的 AI 工具可以通过接口拉取这些组件的名称和属性，但面临一个根本性问题：

**AI 拿到了零件清单，但不知道这些零件之间怎么组装。**

例如：
- "Header" 里面可以放 "NavItem"，但不能放一个独立的 "Button"
- "表单页面" 需要同时加载 "FormContainer"、"InputGroup" 和 "SubmitBar"
- "数据看板" 场景下优先推荐 "ChartCard" 而非 "ImageCard"

这些隐含的组合规则存在于设计规范里，但从未被结构化地传递给 AI。结果是 AI 生成的页面结构经常在逻辑上不合理，需要大量人工修正。

**MAX 的组合推理层就是解决这个问题的。**
