# 企业 FAQ

## 安全与部署

**Q: MAX 的数据在哪里处理？**
A: 所有组件数据和规则推理均在本地环境完成。MAX 采用本地部署模式，不依赖云端服务，设计数据不出企业内网。

**Q: 组件数据会外传吗？**
A: 不会。MAX 在本地读取组件 JSON 数据，推理引擎在本地执行，不向外部发送任何设计数据。

**Q: 支持哪些部署方式？**
A: 本地安装 + 命令行调用 + API 集成。可根据企业 IT 环境灵活配置。

## 集成与兼容

**Q: MAX 需要什么样的输入数据？**
A: 组件 JSON 数据（包含名称、属性、变体信息即可）。支持从设计工具中导出或通过 API 拉取。

**Q: 现有设计系统需要改造吗？**
A: 不需要。MAX 在组件数据之上增加推理层，不要求修改设计系统的现有结构。组件无需重命名或重构。

**Q: 支持多个设计系统吗？**
A: 支持。MAX 可以同时管理多个设计系统，每个独立配置规则库，互不干扰。

## 投入与回报

**Q: 部署周期多长？**
A: 基础部署在 1-2 周内完成。规则配置的周期取决于组件库规模和复杂度，通常在 2-6 周内完成核心规则的搭建。

**Q: 需要专人维护吗？**
A: 初期建议指定一名熟悉设计系统的成员负责规则配置。日常运行后，维护成本较低——新增组件和规则变更通常每次只需几分钟。

**Q: 投资回报怎么衡量？**
A: 三个可量化指标：
- **AI 生成页面的一次通过率**（无需人工修正可直接评审的比例）
- **组件复用准确率**（AI 推荐的组件被实际采用的占比）
- **设计到开发阶段的返工率**（因组件使用错误导致的修正工时）
